# 🌍 WanderWorld – Travel & Tourism Website

## About the Project
WanderWorld is a web-based Travel and Tourism Management System that helps users explore popular travel destinations and make travel bookings online.

## Features
- Explore popular tourist destinations.
- View destination details, prices and trip duration.
- Book travel packages online.
- Submit contact and enquiry forms.
- Store destination and booking information using Supabase.

## Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- Supabase

## Installation and Setup

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open the backend folder in the terminal.
4. Install dependencies:

```bash
npm install
```

5. Configure your Supabase credentials in the backend `.env` file.
6. Start the backend:

```bash
node server.js
```

7. Open `frontend/index.html` using Live Server.
